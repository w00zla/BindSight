# Bundled image-maps

One folder per image-map, named by its id (a UUID): `<id>/imagemap.json`
plus the one image file it references by bare file name (png/jpg/jpeg/webp).
`imagemap.json` is format 3 — see `src/imagemap.rs` for the schema. Bundled
image-maps are read-only in the app; users clone them.

The four shipped folders (`4b7a2c1e-0001-4000-8000-000000000001` to
`…0004`: Keyboard US, Keyboard DE, Xbox controller, PlayStation controller)
are generated by `scripts/gen-imagemaps.py`, which holds each device's
geometry once and writes both `image.png` and `imagemap.json` from it. Do
not edit them by hand — change the script and re-run it.
